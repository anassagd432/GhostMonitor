# Ghost Monitor - Privacy Policy Statement

**Effective Date**: August 2026

## 1. 100% On-Device Data Collection
All system metrics, performance stats, process information, hardware details, and network activity monitored by Ghost Monitor are collected and processed **100% locally on your Mac**.

## 2. Zero Telemetry & Analytics
Ghost Monitor contains:
- No tracking scripts
- No crash analytics SDKs
- No cloud backends
- No user account systems
- No advertising networks
- No third-party network connections

## 3. Transparency & Local Export
Any diagnostic report generated through Settings is created locally and saved only when explicitly requested by the user via `NSSavePanel`.

---

*"All system monitoring data remains on this Mac."*
