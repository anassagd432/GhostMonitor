# Ghost Monitor - Product Roadmap

## Short-Term Enhancements (v1.1)
- Advanced per-process network traffic breakdown (`nettop` / socket stats abstraction)
- Custom metric threshold alert notifications via macOS User Notifications (`UNUserNotificationCenter`)
- Per-core CPU load sparklines in process detail view

## Medium-Term Features (v1.2)
- Optional standalone menu bar popover dashboard view
- Disk SMART health reporting via IOKit NVMe/SATA driver attributes
- Modular widget extension for macOS Notification Center

## Long-Term Vision (v2.0)
- Optional lightweight helper daemon for advanced SMC thermal sensor monitoring
- Energy impact approximations based on task info power counters
